A fern writes its own out-of-office reply, counting its absence not in working days but in thirst. The joke turns the plant's neglected, unwatered life into the clock itself, and promises a return only when its leaves recover.

## Run

```sh
node main.ts
```

Writes one line to `/output/entry.txt`, with no trailing newline.
